# Magic Fashion Mirror AI

Espejo mágico interactivo de moda usando:

- Computer Vision
- MediaPipe
- JavaScript
- Realidad aumentada
- GitHub Pages

## Publicar

1. Crear repositorio en GitHub.
2. Subir todos los archivos.
3. Ir a Settings > Pages.
4. Seleccionar Branch main.
5. Guardar.

La página quedará disponible como GitHub Pages.
